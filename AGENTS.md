# Oveview
containers is a small project to provide various simple container builds in a controlled way principally for personal project use.

# Principals / Guides
1. Containers should be built with github actions
2. The default location for the container registry is the ghrc.io registry of github. 
3. Containers are released publically
4. Red Hat technology is used by default. E.g. Use podman not docker. Use sensible red hat base images by default
5. Don't skip on security
